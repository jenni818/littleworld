# Little World MVP
Mobile-first prototype for a personalized daily world-news audio show for children aged 3–7.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

## Current V0
- Mobile-first landing screen
- Child name, age, and interests onboarding
- Personalized Today screen
- Episode/player UI using sample content
- Question of the Day
